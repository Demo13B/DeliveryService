# Служба доставки.
## Салихов Тимур

Проект выполнен на языке JavaScript с применением библиотеки Express. В качестве базы данных используется MongoDB.

Стек:
- JavaScript
- MongoDB
- Mongoose
- Express
- Socket.IO
- Docker

Для проекта написан Dockerfile, который производит подготовку контейнера, а также compose файл для запуска. По умолчанию приложение запускается командой yarn start. Для запуска в режиме отладки используется команда yarn start-dev. Настройка приложения осуществляется через переменные окружения, которые приведены в .env-example.

Описание:
- APP_PORT - задает порт на котором запускается приложение
- MONGO_USERNAME - имя пользователя при инициализации MongoDB
- MONGO_PASSWORD - пароль при инициализации MongoDB
- MONGO_URL - полный адрес базы данных
- SESSION_SECRET - секрет для хеширования сессий
